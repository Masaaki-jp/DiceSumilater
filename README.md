# DiceSumilater 🎲🎲

通信型のWebゲーム（チンチロなど）を想定した、**超軽量・超高速なサイコロシミュレーター**です。
GitHub Pagesにて実際に動作するデモを公開しています。

👉 **[デモページはこちら](https://masaaki-jp.github.io/DiceSumilater/)**

---

## 💡 このプロジェクトのコンセプト：通信量の極小化（ハック）

通常のWebゲームでサイコロの「コロコロ転がるアニメーション」を実装する場合、GIF画像や動画ファイル（数十KB〜数百KB）を通信で送るのが一般的です。しかし、それでは通信量がかさみ、テンポも悪くなります。

このシミュレーターでは、**「画像」を一切使わず、「4バイトの絵文字」と「ブラウザの描画パワー（CSS）」だけでサイコロの回転を表現**しています。

### 🚀 圧倒的な軽量化の仕組み

1. **データ通信量はわずか数バイト**
   サーバーからクライアント（ブラウザ）へ送るデータは、`{"dice1":3, "dice2":5}` のような、たった**20バイト程度のJSONテキストのみ**。
2. **描画負荷をユーザーの端末に丸投げ**
   「🎲」という絵文字のフォントデータは、ユーザーのスマホやPC（OS）に最初から内蔵されています。プログラム（CSS Animation）を使って端末のGPUで回転させているため、サーバーの転送量や負荷はほぼゼロです。
3. **出目の確定（3バイトのUnicode記号）**
   アニメーション終了と同時に、4バイトの `🎲` から、3バイトのサイコロの出目記号（`⚀` 〜 `⚅`）へフロントエンド側で瞬時に差し替えます。
